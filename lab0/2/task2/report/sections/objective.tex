\section{实验目的}

本实验使用 OpenCV 官方样例中的 aloe 双目图像，完成从左右图像到视差图和相对深度图的基本处理流程。实验目的如下：

\begin{enumerate}
  \item 理解双目视觉中对极约束、视差与深度之间的关系；
  \item 掌握 OpenCV 图像读取、灰度预处理和 \texttt{StereoSGBM} 立体匹配接口；
  \item 将匹配器输出的定点视差转换为像素单位的浮点视差，并进行有效区域筛选与可视化；
  \item 在缺少与图像对配套的相机标定参数时，计算并分析无物理单位的相对深度代理；
  \item 保存真实运行产生的输入图、视差图、有效掩码和相对深度图，并据此分析实验结果。
\end{enumerate}

本实验的深度结果限定为相对深度，不将未标定的结果解释为米、厘米等物理单位。
