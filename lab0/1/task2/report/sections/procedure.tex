\section{实验步骤}\label{sec:task2-procedure}

\begin{enumerate}
    \item 准备平面棋盘格，实际测量方格边长，并记录每行、每列内角点数。
    \item 使用手机在不同距离、平移位置和倾角下拍摄多幅清晰照片，记录手机型号、摄像头模式和图像分辨率。
    \item 将照片放入输入目录，逐张读取并检查图像是否成功加载；读取失败的文件只记录为失败项，不应使其余图像停止处理。
    \item 使用 \texttt{cv2.cvtColor} 将彩色图像转换为灰度图，再使用 \texttt{cv2.findChessboardCorners} 检测棋盘格内角点。检测成功的图像记录二维角点，检测失败的图像输出文件名和失败状态。
    \item 对检测成功的角点调用 \texttt{cv2.cornerSubPix} 进行亚像素优化，并将优化终止条件和窗口设置保持为程序中的明确配置。
    \item 根据标定板内角点规格和方格边长生成 \(Z_w=0\) 的三维物点，将其与每幅图像的二维角点一一对应。点的几何定义遵循式\ref{eq:task2-homography}。
    \item 检查有效图像数量和图像尺寸一致性。若有效图像数量不足以稳定估计参数，则给出提示并要求补充采集；不同尺寸的图像不能直接混合标定。
    \item 调用 \texttt{cv2.calibrateCamera} 估计相机内参矩阵、畸变系数以及各幅图像的旋转向量和平移向量。内参矩阵的含义见式\ref{eq:task2-intrinsic}，畸变模型见式\ref{eq:task2-radial-distortion}和式\ref{eq:task2-tangential-distortion}。
    \item 对每幅有效图像使用 \texttt{cv2.projectPoints} 重投影三维物点，依据式\ref{eq:task2-point-reprojection}计算角点误差，并汇总平均重投影误差和 RMS。
    \item 将相机矩阵、畸变系数、RMS、平均重投影误差、有效图像数及每张图像的检测状态保存到输出结果中；如程序启用校正功能，再使用 \texttt{cv2.undistort}生成校正图像。
    \item 将实际运行日志中的结果填入第\ref{sec:task2-results}节，并按照第\ref{sec:task2-analysis}节分析参数合理性和数据质量。
\end{enumerate}
