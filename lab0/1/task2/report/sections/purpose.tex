\section{实验目的}\label{sec:task2-purpose}

本实验面向手机相机，使用 Python 调用 OpenCV 完成基于平面棋盘格的相机标定。实验目的如下：

\begin{enumerate}
    \item 理解世界坐标系、相机坐标系、图像坐标系和像素坐标系之间的关系，掌握针孔相机模型；
    \item 区分相机内参数与外参数，理解主点、焦距和镜头畸变系数的物理含义；
    \item 掌握棋盘格角点检测、亚像素优化和 \texttt{cv2.calibrateCamera} 的基本使用方法；
    \item 输出相机内参矩阵、畸变系数和每幅有效图像对应的位姿，并用重投影误差评价标定结果；
    \item 在真实采集数据落地后，分析标定板覆盖范围、拍摄姿态和角点检测质量对结果的影响。
\end{enumerate}

本报告只记录实验方法和真实结果的登记位置。手机型号、图像数据及标定数值必须由实际采集和程序运行产生，不以预设值替代实测结果。
