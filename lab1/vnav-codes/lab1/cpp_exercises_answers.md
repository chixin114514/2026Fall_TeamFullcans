# C++ 练习答案

## Operators

1. `i = 2`，`j = 1`。先执行 `++i`，再执行 `i++`。
2. 输出 `b`，因为 `i < 42` 为假。

## References and Pointers

1. 输出 `10 10`。`ri` 是 `i` 的引用。
2. 输出 `1764`。指针先取到 `42`，再执行 `42 * 42`。
3. 输出 `0`。`i + 2` 指向第三个元素，右侧为 `24 - 24`。
4. 输出 `0`。`reset` 通过引用直接修改 `j`。

## Numbers

1. `short`、`int`、`long`、`long long` 都是有符号整数类型，表示范围至少依次不小于前者；具体位宽由平台决定。通常 `short` 较小，`int` 是常用整数类型，`long` 至少 32 位，`long long` 至少 64 位。
2. `float` 通常是单精度，`double` 通常是双精度，后者精度和表示范围更大。`i = 3.14` 把浮点数转换为 `int`，因此 `i` 为 `3`。
3. 有符号类型可以表示负数，无符号类型只能表示非负数且范围上限更大。`unsigned char c = -1` 会把 `-1` 转换为该类型的最大值；8 位 `unsigned char` 中 `c` 为 `255`。
4. `i` 为 `0`，因为非零整数在条件判断中为真。
